# Task 5: Decision Trees and Random Forests 🌳🌲

## Objective
To learn and implement tree-based models for classification using the Heart Disease Dataset.

## What’s Covered
- Trained and visualized a Decision Tree
- Analyzed and controlled overfitting using max_depth
- Trained a Random Forest and compared performance
- Interpreted feature importances
- Evaluated models using 5-fold cross-validation

## Tools Used
- Python
- Scikit-learn
- Matplotlib
- Graphviz (for tree visualization)

## Results
- Decision Tree Accuracy: ~83%
- Random Forest Accuracy: ~87%
- Random Forest had better generalization (less overfitting)
